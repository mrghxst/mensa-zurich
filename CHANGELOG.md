# Changelog

All notable changes to Mensa Zürich. Versions match the release tags (`v<version>`).

## 1.0.0 (2026-10-29)

First release.

- Menus of the ETH and UZH mensas for this week and next, with photos, allergens, nutrition and prices
- Smart sorting, filters by campus, status and diet, favorites and hidden mensas, four list layouts
- Opening hours, address and map link for each mensa
- Menu reminders at a set time, optionally only on campus
- ETH Legi card in the app, as a Quick Settings tile and as an app shortcut
- "Today's menu" home-screen widget
- Standalone Wear OS app
- English, German, French and Italian; light and dark mode; phone, foldable and tablet layouts
