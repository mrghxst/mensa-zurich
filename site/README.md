# Mensa Zürich website

The website of [Mensa Zürich](https://github.com/mrghxst/mensa-zurich), an unofficial Android app for the ETH Zürich and UZH mensa menus. It's live at **https://mrghxst.github.io/mensa/**.

- [Privacy policy](https://mrghxst.github.io/mensa/privacy/)
- [Terms of use](https://mrghxst.github.io/mensa/terms/)

The app, its source code and its releases are in [mrghxst/mensa-zurich](https://github.com/mrghxst/mensa-zurich).

## How this repository works

This repository only holds the published copy of the website. The source lives in the `site/` folder of [mrghxst/mensa-zurich](https://github.com/mrghxst/mensa-zurich) and is copied here by `tools/publish_site.py`, so make changes there, not here. GitHub Pages serves the `main` branch as it is, without a build step.

Questions, bugs or a missing mensa: [open an issue](https://github.com/mrghxst/mensa/issues).
